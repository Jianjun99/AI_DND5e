## 执行与交接

### 实现行为

- 首页内容包区和冒险菜单进入“模型与外观”。横向桌面三栏：资源库、真实 3D 预览、英雄/怪物绑定。原生文件导入与导出、预览待机/步行/攻击/受击/死亡/施法、逐包禁用；已安装包可以删除。选择英雄按 roster ID 保存，怪物按注册 monster ID 保存，默认程序模型可以覆盖作者绑定。
- 固定本地样例 `content/visual-starter/`：原创 CC0 英雄和骷髅，真实骨架和六个动画片段；骷髅缺 cast 映射以验证 idle 回退，并含微小内嵌 PNG。默认不自动替换现有游玩模型。作者重建脚本不改规则。
- 本地 r186 GLTFLoader/SkeletonUtils 与现有 Three.js 对齐，MIT 许可保留。每个实例独立骨架/mixer/HP sprite；模型原型的几何/材质/纹理由缓存租约共享。最后引用释放、解析中退出、部分加载失败均清理；过期响应不挂旧场景。
- T8 注册表增加有限视觉清单；bundle v2 完整携带 GLB base64，v1 旧包兼容。先校验声明文件/二进制/片段/稳定引用/预算，再暂存并重检，复用现有原子安装/回滚。已安装坏资源不进入视觉目录；导出明确失败，不静默丢资源。
- 外观配置只写 `data/visual-settings.json`，不触及角色、活动地图快照、存档版本或 RNG；存档备份原来不含内容包，新外观配置也单独保存，分享时另行导出资源包。配置下次进入冒险生效，禁用/删除/坏包/缺包都可回默认继续旧档。
- Action reply 添加 `visualEvents`：只投影本次同步机械提交中的类型化攻击及 HP/alive 变化，含唯一 eventId。引擎仅两处既有攻击事件补 attackerId，无规则数值变化。视觉立即跟随确认结果，轮询/读档/语言切换不重播；ready GLB 死亡后立即退出可选棋盘，在无命中的展示层最多保留 1.1 秒，再释放。
- 普通冒险继续复用 V1a 实例、T10 面板、2D/3D 切换、浏览器全屏及导航生命周期。资源预览有独立场景生命周期；没有英雄时相机居中，两个实例的完整边界有真实浏览器断言。语言切换保留未保存外观、焦点与同一个 preview canvas；验证失败显示 pack/file/field 和片段名诊断。
- 作者 GLB 的 extras 在完整导出中保留原始字节，实例节点不带作者 metadata；格子和实体命中只由 renderer 锚点提供。测试包故意含伪造 tile/entityId，单元及真实 3D 点击验证稳定目标归属；发布样例不含这些测试字段。

格式、预算、限制与完整导入例子见 [MODDING](../MODDING.md)。关键入口：`server/game/visual-content.js`、`visual-settings.js`、`visual-events.js`、`server/routes/content.js`、`public/js/visual-packs.js`、`views/visuals.js` 与现有 map3d/play。初版不接受外部 URI、任意扩展、压缩或 morph，不做独立动作包/任意骨架重定向；同伴/NPC 仍使用默认程序模型。

4. 禁用包或把绑定选择设为默认，再次进入同一存档：恢复程序模型，继续移动/攻击/结算。共享核心样例不能删除，已安装示例可以通过确认后删除。
5. 修改清单引用不存在的片段后尝试导入，界面显示诊断，原包保持完整。此流程无需开启 AI 或外网。
