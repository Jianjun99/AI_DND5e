## 目标场景与尺寸

默认出发后主要看到场景、简短目标、生命/回合与常用行动。角色、背包、任务、详细日志、NPC 对话通过底部工具入口或快捷键浮起，不需要退出冒险。桌面 1440×900 / 1280×800，手机 390×844（竖屏）及 844×390（横屏）。

## 范围与实现约定

按三段推进，每段形成截图/行为清单：

1. **地图与 HUD**：在现有布局上统一地图优先模式和旧 immersive，清理重复 CSS 覆盖，设默认偏好与可回到旧紧凑/战术显示的入口。桌面无面板时地图容器至少占游戏主区域宽度 80%、高度 70%，比例计算明确不含浏览器栏；这是容器尺寸，不要求地图 tile 被拉伸铺满。保留当前目标、战斗回合/行动经济、HP/关键异常和移动/攻击/结束回合，不能为放大画面隐藏关键状态。
2. **统一浮层**：轻量 panel manager 复用现有 panel factory；一次只展开一个主面板，已有结算/NPC 模态等通过同一层级协调。面板开关不销毁 renderer。明确地图/HUD/面板/阻塞模态 z-index、pointer-events；打开背包时点击不穿透攻击，输入时 WASD 不走路，Esc 逐层关闭，焦点回到触发按钮。结算锁不能被 Esc、快捷键或浮层关闭绕过。日志默认短摘要，可展开历史，不删除伤害/死亡/选择结果。
3. **手机与性能**：竖屏使用底部抽屉/全宽面板，保留地图操作入口；横屏不被 HUD 占满。考虑 safe-area 和虚拟键盘。map3d 通过 ResizeObserver/明确 resize 适配容器变化，保持像素上限与 camera 位置；2D 坐标映射使用当前 rect。关闭 observer/listener、dispose 等遵循原 cleanup。移动端不新增阴影/后处理开销。

所有新增文字直接复用 T9a；界面选择不提交 game action 或改变 RNG。若需要移动既有 DOM，保留节点事件与视图身份；不复制引擎规则/整套 panels。

### 可照做的试玩

1. 使用已有游戏服务，或在 PowerShell 执行 `Set-Location 'G:\ai_DND'` 后 `npm start`，人工浏览器打开 `http://localhost:3000`。快速开始选英雄，准备页选 The Sunless Crypt/easy 后出发；如有路遇先完成当前选择并进入。自动验收仍只能用 Docker verify。
2. 默认大地图中点高亮地块，确认顶部生命/目标/教学。进入战斗检查回合/行动经济/攻击/结束回合；职业技能在角色 C 内，原 1–5 快捷物品可用。
3. 点底部角色/背包/任务/日志/对话或 C/B/Q/L/T，每次只开一个主面板。角色内再开背包，Esc 返回角色内按钮，再按 Esc 返回底部角色入口。对话中输入 WASD，角色不走路；留草稿并在菜单→设置→游戏切语言，返回后草稿和地图仍在。L 查看完整历史。
4. V 或右上战术按钮来回切，偏好会保留；小地图的完整 2D/3D 切换后点击地块。用手机/设备模拟查看 390×844、844×390；抽屉关闭、攻击/结束回合、背包按钮均可达。
5. 撤退时看结算保存状态：未确认/失败期间关闭、Esc、返回入口和浏览器返回均不能绕过；失败可重试，确认后可关闭查看地图或正常回城。山谷哨门和平/战斗路线与读档步骤沿用 T6 交接。
