## 范围与实现约定

分三段形成可检查结果，全部完成才关闭此任务：

1. **内容展示**：先确定翻译 overlay（以 definition ID / 场景 ID / 选项 ID 为索引）或可选 localized 字段契约，给出一份最小示例，经 T8 校验。增量添加发行的七张地图、NPC/主线/同伴/推荐英雄与规则名称的两语言资源。翻译资源只含文字，不复制 HP/DC/价格/XP/效果等数值。服务端决定有效定义与允许暴露的文本；客户端不得因翻译把整张隐藏地图发下来。显示名和内部 canonical 名分离，装备 uniqueId、className、引用和战斗判断不变。
2. **结构化文字**：为事件与固定日志增量提供 messageKey + params（由引擎真实结果填充）并保留 text；使用展示边界进行翻译。params 可用实体 ID/已允许显示的名称，不能重算伤害或骰值。为当前发行事件列迁移清单并覆盖关键战斗/掉落/检定/奖励/任务结果；词缀装备显示由 base ID + affix ID 组合，不修改持久 uniqueId。旧纯 text 日志按原文显示并明确是历史记录，不做猜测性翻译/改档。
3. **AI 与语音**：res.locals.locale 在请求进入时固定到模型任务上下文；异步任务晚返回仍关联原 actionId 与语言。DM/NPC/回顾/实体描述/任务生成 prompt 与无模型兜底均按语言，移除写死 Sunless Crypt 的跨地图提示。生成内容记录 language 来源，旧聊天保留原文；切换不重发行动、不重写历史、不额外收模型费用。TTS 选择同语言 voice，缺失时提示或静默停止朗读，正文保留。AI 中文检索需处理汉字分词/匹配，并为已发现/该 NPC 可知的事实做过滤，不泄漏未来分支/隐藏房间。

选择具体 overlay 字段结构可以自行决定，但先记录在 ARCHITECTURE/MODDING 并纳入 validator；不得修改纯数值规则或把翻译作为模块重新注册引擎数据。

## 本次不包含

实时翻译玩家每句话、给历史 AI 聊天补译、要求模型在线才能显示固定文本、自然语言裁判升级、通用脚本式模组语言。第三方没有中文译文时允许原文回退并在内容信息说明可用语言；不能伪装成已经完整翻译。

## 可照做的试玩

1. 项目拥有者使用当前源码重新启动已有游戏服务，或在 PowerShell 执行 `Set-Location 'G:\ai_DND'`、`npm start`，人工浏览器打开 `http://localhost:3000`。若使用游戏 Docker 镜像，需重新构建再启动；自动验证仍统一使用专用 `npm run verify` 容器。
2. 顶部选择“简体中文”，快速开始创建一位英雄；在准备页选择“山谷哨门”、easy、单人。阅读主线页、职业/装备说明，出发后打开背包 B、任务 Q、日志 L。地牢中通过菜单→设置→游戏→语言切换 English，然后关闭设置；检查物品/任务/已发现房间/固定日志的文字变化、实际数字相同。聊天 T 留下未发送草稿，切换后检查输入和地图保留。历史原文标记下的旧日志/旧 AI 回复保持原文。
3. 和平路线：走到 `(3,3)`，互动 `(3,4)` 木箱取得通行印；再到 `(5,3)`，点击守门人并选择“交回通行印，和平通过 / Return the seal and pass peacefully”。检查一次消耗、打开通路与两语言的已确认记忆；AI 关闭时也能对话并完成路线。
4. 新开一次山谷哨门，选择“选择交战，用武力通过 / Fight your way through”；用攻击/法术/结束回合完成真实战斗，检查戒备记忆及伤害、XP/掉落日志。两路线都可继续到 `(11,3)` 互动 `(12,3)` 圣物，再回 `(1,3)` 营火；确认结算成功后回城、重新出发，NPC 引用上次真实选择。原战斗难度与奖励没有调整，失败可按既有复活/重试入口继续。
5. 桌面与约 `390×844` 手机竖屏分别查看两语言的词缀装备、长任务、完整日志和遭遇选项。语音需本机具有正文语言的 voice；没有匹配 voice 时正文仍显示、停止朗读。使用 Piper 时在设置→语音声明该服务的实际语言；未声明或与正文不同则只尝试同语言浏览器 voice。并发慢模型、超时、缺 voice、迟到音频由容器的确定性 mock 验收，人工试玩无需修改档案或连接真实模型。
