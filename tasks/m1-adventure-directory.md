### 行为与兼容

- `/api/content` 的 `adventures/waypoints/roads` 与 `/api/city/info` 的 `adventures/mapNodes/mapRoads` 由同一函数编译。保留旧 `maps` API 的公开目标和白名单译文；旧包不用补字段即可在两个正常入口选择。
- 所有有效静态地图进入目录；可选 `adventure.waypoint` 才进入区域 SVG。`adventure.levels` 只是推荐信息，不限制等级或改变难度。原有八张地图的位置/道路迁入各自地图文件，城镇路由不再维护地点表或信使特判。城镇、无尽、周试炼仍使用原系统 ID；生成地层不增加目录项。
- 同一 UI 组件提供标题/来源包/简介/推荐、搜索和来源筛选、原文回退提示。语言切换原地更新，保留输入和焦点；视图拥有唯一 locale listener，组件监听用 AbortController 随重绘/离页释放。刷新和开局期间锁定目录。
- 正常加载或“刷新目录”反映导入/替换/删除；已删项在准备页回到有效地图，在城镇回到安全城镇入口。开局发现目录过期也刷新，失败开局不改玩家资源。活动地图使用已有快照；测试确认删包后仍可取圣物、胜利并结算，重复结算不重复写档。跨地图楼梯仍服从既有缺失目标错误契约，不保证被删除的外部地层可进入。
- 复用 T8 校验和安装事务，拒绝无效坐标/字段/系统 ID/道路、重复端点和重复无向道路；替换不能移除其他包依赖的地点。删除沿用既有行为，失去依赖的定义会被注册表排除。不迁移或批改玩家档案。
