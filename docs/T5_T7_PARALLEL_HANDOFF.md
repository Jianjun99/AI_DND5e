**整合轮发现并修复的三个真实 bug（均在 `public/js/views/play.js`，非 T5/T7 各自范围，属共同流程暴露的预存问题）**：
1. **圣物在 UI 中不可点击**（严重、预存于 HEAD）：crypt 地图祭坛与圣物同在 (12,22)，点击处理器 `find` 只取首个对象，祭坛永远遮蔽圣物——主线第一幕无法在 UI 内完成（API 层测试与回放机器人不经过渲染，历史验收用过 fixture，故从未暴露）。修复：同格多对象点击循环选择（纯目标选择层，服务端仍按 objectId 裁决），祭坛与圣物均可交互。
2. **自然 1 死亡的存档会白屏**（严重、预存）：第 3 次失败的死亡豁免若掷出自然 1（+2 失败）会让 `deathSaves.fail=4`，渲染 `'○'.repeat(3-4)` 抛 `Invalid count value: -1`，整个地牢视图崩溃、无法打开——任何自然 1 阵亡的玩家都会触发。修复：显示计数钳制到 [0,3]。
3. **侧栏复活不重置 `summaryShown`**：从侧栏“Recover at camp”复活后再死亡时，结算面板不再自动弹出，玩家无 UI 入口结算（服务端 endSeq 正常盖章）。修复：侧栏 respawn 与总结面板 respawn 行为一致（重置 `summaryShown`）。
