## 本轮发现与修复

`public/js/views/overworld.js` 在 SVG `<text>` 内调用 `contentLabel`。该 HTML helper 返回 `<span>`，浏览器因此提前结束 SVG；随后无光墓穴等地点被解析到地图外，失去正常绘制和命中区域。不是地图内容文件被删除。

真实旧 DOM 证据：`artifacts/verify/2026-10-04T02-41-24-231Z-73e469f2/screenshots/t11-failure-9235-0.json`，SVG 起点 8714、结束 12576，无光墓穴节点 12905，后续节点已在 SVG 外。该截图原用于路由问题，也保留了此地图错误。

本轮改为 SVG 原生 text 文字叶子，直接绑定既有 `data-i18n-display` / fallback，不嵌 HTML。地区/道路文字原地绑定双语，侧栏地区使用 descriptor。架构手册已补充这一约束。

新增浏览器回归在 `tests/e2e/review-regressions-cdp.test.mjs`：1280×720、1440×900、1920×1080，两语言；十个地点须属于当前 SVG、名称实际可绘制；切语言保留同一 SVG、不发送行动；实际鼠标命中无光墓穴/失踪信使，打开正确可用的出发控件；角色数据不变。仅存在 `[data-node-id]` 不能证明地点画在地图里。

本轮完整验证：`npm run verify -- --timeout=1200` **退出 0**；eslint、tsc、全部 **37 套件（12 CDP）** 与 smoke 全绿。Review CDP **202/0**，其中地图新增 **95 项**；HP 矩阵 **10/0**，T11 集成 **11 cases / 350 assertions**。证据 `artifacts/verify/2026-10-04T06-02-00-897Z-9155f551/`，`result.json` 确认 `cleanupComplete=true`、`timeout=false`，固定验证容器已移除。新增三尺寸/两语言 PNG/DOM 保留并已实际查看。只改显示与回归，无规则/数值表变化，无需追加 balance。

地图截图已确认地点恢复。后续布局观察：现有标记依赖 emoji，容器字体会把部分符号画为方框，部分相邻地点名称重叠。中文页顶部职业/种族及侧栏等级范围/部分地区仍显示原文；应使用既有 i18n 与服务端 descriptor 收尾。横向界面模块应使用稳定 SVG 标记并整理名称位置；这些问题与 SVG 截断分别处理。

### V1：可替换角色/怪物模型和动作

两段状态：**done（2026-10-04，均经用户明确授权与完整验收）**。第一段的可替换实例/程序小样见 [第一段交接](../tasks/v1a-visual-instance.md)，第二段的有限 GLB 包/绑定管理见 [第二段交接](../tasks/v1b-visual-packs.md)。以下保留原交付目标与边界，最终统计以本页顶部和相应交接为准。

可行，但现有 `createCharacterModel` / `updateModelAnimation` 是程序关节模型，不能直接把任意外部动作套上去。

首版建议 **GLB 模型自带动画**，在清单中把片段名称映射为 idle/walk/attack/hit/death，cast 可选。[GLTFLoader](https://threejs.org/docs/pages/GLTFLoader.html) 提供场景和动画片段，[AnimationMixer](https://threejs.org/docs/pages/AnimationMixer.html) 负责实例播放/清理。仓库 Three.js 为 r186，新增 loader/骨架克隆工具须匹配版本并本地提供，测试不依赖 CDN。

入口：`models3d.js`、`map3d.js` 的创建/动画/清理、内容 API/校验、现有 renderer 回归。不物理拆分引擎。

第一段：建立视觉实例接口（如 root/update/play/dispose），默认实现仍使用当前程序模型，使渲染器不直接依赖某套关节字段。先做一个小样与生命周期验证。

第二段：版本化视觉资源包、有限 GLB 清单、本地资源服务和内容管理入口；清单含稳定 model ID、文件、缩放/朝向、片段映射和绑定。英雄可选择外观，怪物按稳定 monster ID 绑定。缺包/坏模型自动回默认模型，仍可继续存档。

关键约定：

- 视觉描述独立于机械定义。外形/动作不修改 HP/AC/速度/伤害/掉落/职业或怪物 ID，格子位置和命中由引擎决定。
- 动作跟随已确认移动和结构化结果；轮询/读档不重播同一攻击。不要按中文/英文日志猜动作，也不等动画结束才裁决伤害。
- 同一 GLB 的骨架与动画先一起交付。独立动作包只有骨架兼容才接受；跨任意骨架自动重定向不属于首版。程序关节与 glTF 骨架不是同一接口。
- 资源包只含模型/纹理/描述，按已声明路径访问。先校验→暂存→原子安装；旧地图 JSON 包保持兼容，旧导出不能静默丢模型资源，新资源包必须能完整导出/再导入。
- 明确文件/纹理/几何预算、缓存引用和卸载。缺片段能回 idle；同模型多个实例的骨架/mixer 各自独立。视图离开后迟到加载不挂旧场景；纹理/几何/mixer 按归属释放。
- 先交付一个英雄、一种怪物的替换样例和预览/绑定/禁用，再覆盖同伴/NPC。材质扩展也走同一描述与展示接口。

验收：多个相同怪物独立动画；移动/攻击/受击/死亡、缺片段回退；点击仍对应原实体；读档/重复结果无重复攻击；禁用/删包可继续旧档；迟到加载和反复进出不留资源。换模型前后相同行动的引擎状态和 RNG 一致。用本地固定小 GLB 样例，完整 Docker verify 加真实浏览器检查。
