T11，2026-10-03。一个独立支线，不改变四幕主线。单张 25×15 小地图，两个关键 NPC：守桥人艾芮（Iris）与信使里奥（Lio）。玩家受托寻找未送达的渡口账册；账册记录了过桥税被挪用于安置逃难者。艾芮不知道里奥为何失踪，里奥不知道玩家怎样过桥，后续回应只来自玩家已裁决并带来的事实。

## 身份与记忆边界

- `storyId=missing-courier` 是稳定内容命名域；事实 ID 仍为 `saveId:mapId:sceneId`，独立英雄的档案不会共享。
- `requiresScene` 只查当前 save 中同地图已 resolved 的实例；旧局永久事实不会替本局解锁。跨图/后续内容可按 storyId 识别永久事实，不能把场景 ID 当全局主键。
- 成功/失败的 text、display descriptor、实际费用/物品/检定与两位 NPC 回应由引擎记录。刷新/重复选择不会再次收费、给账册或掷骰；receipt 修复只恢复事实，不重复发奖。
- 当前场景以外的未来对白、未选结局和效果从 API 移除。NPC 模型只看到该 NPC 的已确认记忆与目前可见合法选择；模型关闭/超时/迟到不妨碍任何阶段。
- 回城可查看持久故事摘要；新 delve 中两位 NPC 会记得上次真实选择，但三阶段重新开始。旧 T6、旧包/旧档继续使用原协议。
